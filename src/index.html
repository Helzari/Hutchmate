Pick each parent's colour, then add any hidden genes you know they carry. The odds below update straight away.

Expected : colour

Expected : coat & type

How to read the genes. Each animal has two copies of every gene, one from each parent. The first box is the copy you can see. The second box is the hidden copy it may carry. If you don't know, leave both the same; the odds then assume no hidden genes. A litter with an unexpected colour or coat tells you a parent is a carrier.
